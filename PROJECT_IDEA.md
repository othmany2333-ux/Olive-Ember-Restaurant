## Idea

Olive & Ember is a responsive, multi-page restaurant website designed for two types of users: customers and restaurant administrators. Visitors can explore food categories, search and sort dishes, and learn about the restaurant. After signing in, customers can manage a demo shopping bag, place a sample order, follow its status, update profile details, and send a message or review. Administrators use their own dashboard to manage food items and categories, review customer orders, moderate reviews, update user roles, and examine lightweight reports.

## Why this idea fits the course

The project brings together real-world interface workflows and the principal React topics in the training section. It uses reusable React components, props, React Router, protected routes, useNavigate, useState, useEffect, useContext, a custom Hook for local persistence, and Material UI components with an application-wide theme. Search, category filters, sorting, modal dialogs, and a collapsible sidebar demonstrate interaction design and responsive behavior.

## Main sections

1. Landing page before sign-in
2. Signed-in customer home
3. Menu and food search/filter/sort
4. About and Contact pages
5. Shopping bag and demo checkout
6. Customer dashboard, profile and messages
7. Administrator dashboard for CRUD, orders, users, categories, reviews and reports
8. Login and registration

## Technical scope

The project is a **front-end teaching prototype** built with React.js, Vite, React Router and Material UI. It stores example data in browser localStorage for demonstration without a back-end service. It does not process payments, send real email or offer production-grade security. A real deployment would require a backend, database, secure authentication, authorization and appropriate data protection.
